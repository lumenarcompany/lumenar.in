Your agent shouldn't pay for the same tokens twice.

Lumenar builds Inferstack, a session-aware inference gateway for AI agents on open models. It keeps each session on the engine that already holds its cache, sends each step to the cheapest model that fits, and records what every request really cost.

Most of an agent's bill is re-reading.

What Inferstack does

It sits between your agent and your engines. Your agent keeps using the OpenAI chat API; it adds one header for the session.

Keeps each session on its cache

A session is pinned to the engine it started on, so the engine already holds the prefix and old context is not computed again.

Picks a model for each step

Three policies: cost, balanced, quality. Under balanced, chat and extraction go to the small model; code and reasoning escalate to the large one and stay there.

Meters what each request cost

Served cost is busy engine time times your hourly rate. Reference cost is the list price for the same tokens. Both are stored per request in a ledger.

Fails over

If the chosen engine is unhealthy or returns a retryable error, the request goes to the alternate engine and the response says so.

Publishes eval checksums

A fixed eval suite runs against each model. The score and the hash of the suite ship with the model metadata, so a model swap cannot go unnoticed.

Speaks the API you already use

Streaming and non-streaming chat completions, bearer-token auth, Prometheus metrics, and an inferstack block on every response with engine, cache hit, latency and cost.

Inferstack Console

A client for the gateway on your desk and in your pocket. Chat with a session, watch which engine answered and what it cost, browse sessions and the ledger, and check engine health. One codebase for Linux, Windows, macOS, Android and the browser.

Next: switch models without losing the session

Teams change models for price, rate limits or quality. But a model's cache is computed from its own weights, and each model has its own tokenizer, chat template and tool-call format. So the new model starts cold and the plan can get lost on the way. The next layer is a session log that no single model owns.

  1. Freeze. Stop at a clean turn boundary.
  2. Compact. Fold old turns into the session log, keeping the plan, decisions and open files.
  3. Render. Write the log in the new model's chat template and tool format.
  4. Warm up. One prefill fills the new model's cache.
  5. Check. A short probe confirms the new model knows the plan.
  6. Go on. The agent continues from the same turn.

What it could save at scale

For one 60-turn example task, our cost model puts the bill at $2.95 with no reuse, $0.47 with a prefix cache, and $0.30 when easy steps also go to a smaller model.

Assumptions: $1 per 1M new input tokens, $0.10 per 1M cached, $3 per 1M output; 12K to 84K tokens per turn; 70% of steps can use a model at one fifth of the price. A pilot measures the real numbers on your workload.
